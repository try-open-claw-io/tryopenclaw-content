## Cách sử dụng

Quản lý fanpage Facebook qua chat. Đăng bài (text, ảnh, video), lên lịch đăng, ẩn hoặc xoá comment xấu, trả lời comment và inbox. Skill cần Meta App với token long-lived của page và scopes phù hợp. Tuân thủ rule 24h messaging window của Meta khi reply inbox.

## Hướng dẫn

- Bài đăng hôm qua có ai hỏi giá trong comment không?
- Lên lịch đăng bài bán hàng vào 8h sáng mai
- Ẩn comment spam trên bài tuần trước

## How to use

Manage a Facebook Page through chat. Publish posts (text, photos, videos), schedule them, hide or delete bad comments, reply to comments and inbox threads. Requires a Meta App with a long-lived Page token and the right scopes. The 24-hour Meta messaging window applies to inbox replies.

## Tutorials

- Did anyone ask about pricing in the comments on yesterday's post?
- Schedule a promo post for 8am tomorrow
- Hide spam comments on last week's post
