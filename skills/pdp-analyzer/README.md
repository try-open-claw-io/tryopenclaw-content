## Cách sử dụng

**Cách kích hoạt:** Gõ /pdp-analyzer ở đầu khung chat, rồi dán link trang sản phẩm cần bóc thông tin.

**Kết quả:** Sau khi Agent làm xong, bạn sẽ có bảng facts sạch (tên, giá, tính năng/thành phần, USP, khách gợi ý, tín hiệu tone) để dùng làm nguyên liệu cho các skill viết. Nếu trang thiếu thông tin, Agent hỏi lại thay vì đoán.

## Hướng dẫn

- /pdp-analyzer bóc facts từ link trang sản phẩm này thành bảng để viết bài.

## How to use

**How to trigger:** Type /pdp-analyzer at the start of the chat, then paste the product page URL to extract from.

**What you get:** Once the Agent finishes, you'll have a clean facts table (name, price, features/ingredients, USP, suggested audience, tone signals) to feed the writing skills. If a page is missing details, the Agent asks instead of guessing.

## Tutorials

- /pdp-analyzer extract facts from this product page link into a table for writing.
