## Cách sử dụng

**Cách kích hoạt:** Gõ /content-quality-review ở đầu khung chat, rồi nói bạn muốn review draft, xem performance hay gửi review qua Slack.

**Kết quả:** Sau khi Agent làm xong, bạn sẽ có nhận xét theo 5 tiêu chí, bảng performance từ data thật, hoặc bản review ngắn đã gửi Slack.

## Hướng dẫn

- /content-quality-review review bài trước publish, xem performance, hoặc gửi review qua Slack.

<!-- en -->

## How to use

**How to trigger:** Type /content-quality-review at the start of the chat, then say whether you want to review a draft, check performance, or send a review over Slack.

**What you get:** Once the Agent finishes, you'll have feedback across 5 criteria, a performance table from real data, or a short review sent to Slack.

## Tutorials

- /content-quality-review review a draft before publish, check performance, or send a review over Slack.
