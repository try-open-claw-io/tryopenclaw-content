## Cách sử dụng

**Cách kích hoạt:** Gõ /style-memory-manager ở đầu khung chat, rồi dán bản bạn tự sửa lại (hoặc nêu nhận xét như "bớt trang trọng", "hook mạnh hơn").

**Kết quả:** Sau khi Agent làm xong, giọng viết ưa thích của bạn được lưu vào bộ nhớ và áp cho các bài sau. Agent luôn cho bạn thấy đã ghi nhớ điều gì.

## Hướng dẫn

- /style-memory-manager học giọng viết của mình từ bản mình vừa tự sửa và lưu lại.

<!-- en -->

## How to use

**How to trigger:** Type /style-memory-manager at the start of the chat, then paste your own edited version (or share feedback like "less formal", "stronger hook").

**What you get:** Once the Agent finishes, your preferred writing voice is saved to memory and applied to later drafts. The Agent always shows you exactly what it remembered.

## Tutorials

- /style-memory-manager learn my writing voice from the version I just edited and save it.
