## Cách sử dụng

**Cách kích hoạt:** Gõ /ad-copy-writer ở đầu khung chat, rồi cho biết sản phẩm/ưu đãi cần chạy ads (dán facts hoặc để Agent lấy từ pdp-analyzer), nền tảng (Facebook / Instagram / Google) và giai đoạn phễu. Giả định hình ảnh/creative đã có sẵn — Agent viết phần chữ.

**Kết quả:** Sau khi Agent làm xong, bạn sẽ có 3-5 variant ad copy theo các angle khác nhau (lợi ích sản phẩm, ưu đãi, vấn đề/giải pháp, cộng đồng, sản phẩm cân nhắc cao), mỗi variant đủ headline + primary text + CTA sẵn dùng, kèm một block HOOK OPTIONS để A/B test. Số liệu/ưu đãi thiếu được đánh dấu để bổ sung, không bịa.

## Hướng dẫn

- /ad-copy-writer viết text quảng cáo Facebook cho SP này.

## How to use

**How to trigger:** Type /ad-copy-writer at the start of the chat, then share the product/offer to advertise (paste the facts or let the Agent pull them from pdp-analyzer), the platform (Facebook / Instagram / Google), and the funnel stage. The Agent assumes the creative/image already exists and writes the text.

**What you get:** Once the Agent finishes, you'll have 3-5 ad copy variants across different angles (product benefit, offer, problem/solution, community, high-consideration), each with a ready-to-use headline + primary text + CTA, plus a separate HOOK OPTIONS block for A/B testing. Missing numbers or offer terms are flagged for you to fill in, never made up.
