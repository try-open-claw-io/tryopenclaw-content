## Cách sử dụng

**Cách kích hoạt:** Gõ /product-description-writer ở đầu khung chat, rồi cho biết sản phẩm cần viết mô tả (dán facts hoặc để Agent lấy từ pdp-analyzer) và kênh đăng.

**Kết quả:** Sau khi Agent làm xong, bạn sẽ có draft mô tả sản phẩm và vài biến thể theo kênh — hook mở đầu, tính năng gắn với lợi ích, phần dễ lướt và CTA. Thông số thiếu được đánh dấu để bổ sung, không bịa.

## Hướng dẫn

- /product-description-writer viết mô tả sản phẩm cho SP này.

<!-- en -->

## How to use

**How to trigger:** Type /product-description-writer at the start of the chat, then share the product to describe (paste the facts or let the Agent pull them from pdp-analyzer) and the channel it will be posted on.

**What you get:** Once the Agent finishes, you'll have a product description draft plus a few channel variants — an opening hook, feature-to-benefit copy, a scannable section, and a CTA. Missing specs are flagged for you to fill in, never made up.
