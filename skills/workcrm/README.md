## Cách sử dụng

CRM nhẹ chạy local trong một file SQLite, không gửi data ra cloud. Lưu contact, deal, ghi chú và pipeline bán hàng cho freelancer hoặc shop SME muốn giữ data riêng. Skill tự suy ra kênh tiếp xúc (Zalo, Fanpage, Shopee, TikTok, Lazada, gọi điện, walk-in) khi tạo contact. Xuất CSV bất kỳ lúc nào.

## Hướng dẫn

- Lưu thông tin khách hàng mới: tên, số điện thoại, kênh liên hệ
- Chuyển deal "Đơn sỉ 5 thùng nho" sang trạng thái "đang đàm phán" và ghi giá trị 8 triệu
- Báo cáo pipeline tháng này: bao nhiêu deal ở mỗi giai đoạn, tổng giá trị VND

## How to use

A lightweight CRM that runs entirely from a local SQLite file — no cloud, no third-party API. It stores contacts, deals, notes, and sales pipeline for freelancers or small shops who want their customer data private. The skill auto-infers the contact channel (Zalo, Fanpage, Shopee, TikTok, Lazada, phone, walk-in) on creation. Export to CSV anytime.

## Tutorials

- Save a new customer: name, phone number, and channel they came from
- Move the deal "Bulk order 5 boxes of grapes" to "negotiating" and set value to 8M VND
- Report this month's pipeline: deal count per stage and total VND value
