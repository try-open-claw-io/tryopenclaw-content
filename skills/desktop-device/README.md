## Cách sử dụng

- **Cách kích hoạt:** Gõ `/desktop-device` ở đầu khung chat, rồi nói việc cần làm trên máy tính của bạn (thư mục nào, file nào, lệnh gì). Máy phải đã cài app ClawExperts và hiện Connected trong Settings → Desktop Device; chưa cài thì Agent sẽ hướng dẫn cài.
- **Kết quả:** Sau khi Agent làm xong, bạn sẽ có việc đó được thực hiện ngay trên máy của mình: danh sách hoặc nội dung file, file đã sắp xếp theo kế hoạch bạn đã duyệt, kết quả lệnh vừa chạy. Chỉ thư mục và lệnh admin đã cho phép mới chạy được; việc xoá hay di chuyển luôn được hỏi lại trước.

## Hướng dẫn

- `/desktop-device liệt kê các file trong thư mục Downloads của mình.`

## How to use

- **How to trigger:** Type `/desktop-device` at the start of the chat, then describe the task on your computer (which folder, which file, which command). The machine must have the ClawExperts app installed and show Connected under Settings → Desktop Device; if not, the Agent walks you through installing it.
- **What you get:** Once the Agent finishes, the task is done on your own machine: a file listing or contents, files organised according to the plan you approved, or the output of the command. Only folders and commands your admin allowed can run; deletes and moves are always confirmed first.

## Tutorials

- `/desktop-device list the files in my Downloads folder.`
