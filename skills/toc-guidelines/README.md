## Cách sử dụng

**Cách kích hoạt:** Gõ /toc-guidelines ở đầu khung chat, rồi hỏi về năng lực bạn quan tâm (hoặc để trống để xem tổng quan).

## Hướng dẫn

## How to use

**How to trigger:** Type /toc-guidelines at the start of the chat, then ask about the capability you're curious about (or leave it open for an overview).

**What you get:** Once the Agent finishes, you'll have a tidy rundown of the relevant skills and integrations, what's ready to use, and how to set up whatever's missing.
