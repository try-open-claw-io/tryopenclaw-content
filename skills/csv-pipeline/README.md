## Cách sử dụng

Xử lý file CSV và JSON tại chỗ trên máy. Skill làm sạch dữ liệu, dedupe, chuẩn hoá số điện thoại Việt Nam về định dạng `+84`, join 2 file, pivot long-wide, và xuất báo cáo tóm tắt. Không cần API key, không gửi data ra ngoài. Hỗ trợ encoding UTF-8 và Windows-1258 cho file tiếng Việt cũ.

## Hướng dẫn

- Lọc trùng và chuẩn hoá số điện thoại trong file danh sách khách hàng
- Gộp file đơn Shopee và TikTok Shop, join theo email, xuất Excel
- Báo cáo tỷ lệ null trên từng cột của file lead.csv

## How to use

Local-only CSV and JSON processing. The skill cleans data, dedupes rows, normalizes Vietnamese phone numbers to `+84` E.164, joins two files, pivots long-to-wide, and emits summary reports. No API key, no data leaves the machine. Handles UTF-8 and Windows-1258 encodings for legacy Vietnamese files.

## Tutorials

- Dedupe and normalize phone numbers in a customer list
- Merge Shopee and TikTok Shop orders by email and export to Excel
- Report the null rate per column in `lead.csv`
