## Cách sử dụng

- **Cách kích hoạt:** Gõ `/browser-extension` ở đầu khung chat, rồi nói việc cần làm trên trình duyệt (trang nào, lấy thông tin gì, bấm hay điền gì). Chrome phải đã cài và kết nối Extension ClawExperts (Cài đặt → Extension); chưa có thì Agent sẽ hướng dẫn cài.
- **Kết quả:** Sau khi Agent làm xong, bạn sẽ có việc đó được thực hiện ngay trên tab trình duyệt của mình: nội dung trang đã đọc và tóm tắt, dữ liệu đã lấy, form đã điền. Việc gửi, đăng hay thanh toán luôn được hỏi lại trước; Agent không đăng nhập hay giải CAPTCHA thay bạn.

## Hướng dẫn

- /browser-extension tóm tắt trang mình đang mở.

## How to use

- **How to trigger:** Type `/browser-extension` at the start of the chat, then describe the task in your browser (which page, what to read, what to click or fill in). Chrome must have the ClawExperts Extension installed and connected (Settings → Extension); if not, the Agent walks you through it.
- **What you get:** Once the Agent finishes, the task is done right in your browser tab: the page read and summarised, the data collected, the form filled in. Sending, posting and payments are always confirmed first; the Agent never logs in or solves CAPTCHAs for you.
